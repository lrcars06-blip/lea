# Léa Dupont — Architecture d'intérieur & Décoration

Site vitrine statique (HTML/CSS/JS dans `index.html`). Aucune dépendance, aucun build.

## Déploiement
1. GitHub → New repository → `lea-dupont` → uploader tous les fichiers de ce dossier (à la racine).
2. Vercel → Add New → Project → importer le repo.
3. Framework Preset : **Other**. Build Command : vide. Output Directory : vide (racine).
4. Deploy.

## À personnaliser
- Photos : URLs Pexels dans `index.html` (HTML + objets JS `STY` et `ROOMS`).
- Coordonnées, projets, chiffres, témoignages.
- Formulaire : voir le `TODO` dans le script (Formspree, Resend…).
